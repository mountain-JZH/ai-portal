# 当前发布验收清单

2026-10-21 修订。此文不是执行授权；生产项全部由现场执行人核实，不沿用历史勾选结果。当前主线实现为单次登录与第三阶段维护。参考 [部署指南](../../DEPLOYMENT.md)、[分阶段流程](ecs-deployment-runbook.md)、[拟暂存清单](git-staging-plan.md)。

## 本地提交门槛

- [ ] 按 A/B/C/D 逐文件审核，index 无数据库、WAL/SHM、备份、密钥、凭据、真实 Excel/HTML 或附件。
- [ ] 私密项目 HTML、两个旧验收脚本和未审核实验资源不在拟提交清单。
- [ ] 必需新组件、CSS、后端模块、依赖、测试夹具完整；不能只提交已跟踪修改。
- [ ] 认证、节点、历史、日志更新日期及日期选择器测试通过，非修复 Lint、同源 Build、Python 编译和 diff check 通过。
- [ ] 记录当前候选 SHA；本轮不代执行暂存、Commit、Push。
- [ ] Dify 旧历史地址/Embed 标识由服务负责人复核；不在公开文档复制真实值，不自行改写历史或断开服务。

## 生产取证与备份

- [ ] 确认真实主机、部署根、服务用户、WorkingDirectory、EnvironmentFile、DB/uploads/webroot 和生产版本；不从本地路径推断。
- [ ] 单独审阅服务器 update.sh；本轮不连接或执行。
- [ ] 批准维护窗口，停全部数据库与上传写入方；取得 SQLite Backup API 一致备份及对应 uploads 快照。
- [ ] 保留旧代码、dist、venv 原路径、私有配置及 Nginx/systemd；备份位于 webroot 外并完成恢复演练。
- [ ] 在生产备份副本上迁移两次，旧列数据、管理员 ID/哈希、员工权限、编号及图片引用保持。
- [ ] 理解启动仍调用初始化，多步 DDL 失败可能留下部分结构；迁移失败停止并保全现场。
- [ ] 没有复制本地验收库、示例数据或 .env 到生产。

## adminMO 与员工

- [ ] 生产旧 adminMO 有效且唯一，确认原密码仍由用户掌握；不默认执行密码重置。
- [ ] 同名员工不存在或已正确关联 admin_id；冲突不得自动合并或升级。
- [ ] /login 使用原凭据成功后建立/沿用员工身份，原 admins ID/Argon2 哈希不因升级覆盖。
- [ ] 管理员一次登录可进入门户、项目与后台；旧 /admin/login 安全重定向。
- [ ] 当前不强制首次改密，主动修改/后台重置及旧会话撤销可用。
- [ ] 后台创建市场部维护账号与普通只读账号，不公开注册，不把临时密码写入日志/工单。
- [ ] 如需交互式恢复，已另行批准目标 DB、账号、备份及隐藏输入操作。

## 构建与入口保护

- [ ] 候选使用 lockfile 与批准依赖，独立 venv/候选目录，不原地升级丢失回滚环境。
- [ ] 构建进程显式 VITE_API_BASE_URL=/api；dist 无 localhost API、无 /api/api，浏览器 Network 同源。
- [ ] VITE_DIFY_EMBED_URL 只含批准的公开 Embed URL，不含密钥；实验 HTML、真实数据和源码不进入 webroot。
- [ ] HTTPS 与 SESSION_COOKIE_SECURE=true、HttpOnly、SameSite、Host/协议/Cookie 转发正确。
- [ ] Uvicorn 仅 loopback、不使用 --reload；外部直连端口不可绕过。
- [ ] uploads 与 QsTArT 通过 FastAPI 员工认证；无公开 alias、CDN 或其他静态 location 旁路。
- [ ] 未登录业务 API、附件及工具 401，健康接口 200；普通员工管理/写入 403，市场部管理 403。
- [ ] 修改 Nginx 需另行批准，先 nginx -t 再 reload，不整份覆盖既有 TLS。
- [ ] 5MB 文件与 5m 请求体边界、413/429、可信代理链和限流行为完成实测。

## 业务与视觉

- [ ] 原新闻、Banner、工具、Exchange 记录及图片保留，不重新初始化种子。
- [ ] 四视角、B 三栏、D 四章节、编辑两模式、11 节点、三项历史及 409 保持。
- [ ] 多黄色节点优先最靠前，完成数只计已完成，特殊原文和历史 AC 不被浏览改写。
- [ ] 今日 KPI 与 1/7/30 日筛选基于真实日志、北京时间和项目去重；AG 不参与实时统计。
- [ ] 编号右侧仅一个持久日期标签，跨年含年份；中栏无重复圆点/日期，历史入口可用。
- [ ] 桌面/移动端长文本、长日期、焦点、Escape、滚动和受控图片实际浏览器验收。
- [ ] 由负责人批准 Exchange 开关：未登录先 401；关闭时已登录员工列表/投稿 503；开启后验证真实持久化、重启读取及后台管理。原数据不删除。

## 回滚与批准

- [ ] 认证失败先查 DB 路径、关联、Cookie/代理/CSRF/API 地址，不先重置原密码。
- [ ] 成套旧应用/前端/venv 可回退；若旧版公开业务，保留网关限制或维护页，不能因回滚丢失访问控制。
- [ ] 优先保留增量数据库及新增写入；恢复旧库须再次审批、停全部写入并有数据合并方案。
- [ ] 上线当日和下一工作日检查登录、日志、5xx/413/429、SQLite 锁、图片和磁盘。
- [ ] 发布负责人、验收人、回滚负责人、维护窗口、实际备份位置与批准 SHA 已记录在受控工单。

未勾选的生产项仍阻断部署。Git 提交许可与 ECS 部署许可是两个不同决定。
